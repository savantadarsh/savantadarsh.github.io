03 / Approach

Analysis starts with the right question.

My working principle: a technically correct answer is only useful when it leads to a better decision.

01 — FRAME

Understand the decision

Start with the stakeholder's commercial question, define success, select meaningful KPIs and establish the baseline.

02 — INVESTIGATE

Find the signal

Use SQL, Power BI and analytical methods to validate data, inspect patterns, compare segments and test assumptions.

03 — COMMUNICATE

Make action possible

Translate evidence into clear trade-offs, recommendations, limitations and next steps stakeholders can own.
